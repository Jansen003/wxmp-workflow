# 文章模板

5 个精美的公众号 HTML 模板，所有样式均为内联样式，兼容微信编辑器。

## 设计原则

- **无背景色** — 所有模板不设置 background，适配微信亮色/暗色主题
- **中性文字色** — 使用 #333、#666、#999，微信自动反色后两种模式都可读
- **无重复信息** — 不展示作者和时间（微信文章头部已有）
- **风格靠细节** — 通过边框、线条、字体、间距体现风格差异

## 模板列表

| 模板 | 文件 | 风格 | 适合文章类型 |
|------|------|------|-------------|
| 简约白 | `minimal-white.html` | 大量留白、干净利落 | 干货、教程、工具推荐 |
| 杂志风 | `magazine.html` | 优雅有层次、衬线字体 | 深度长文、观点评论 |
| 科技风 | `dark-mode.html` | 代码字体、渐变线条 | 科技、编程、极客 |
| 卡片式 | `card-style.html` | 模块化分隔、易扫描 | 清单、盘点、资源整理 |
| 渐变色 | `gradient.html` | 渐变线条装饰、年轻活力 | 生活方式、情感、故事 |

## 模板选择策略

**全自动模式：** AI 根据文章类型自动选择最匹配的模板

| 文章类型 | 推荐模板 |
|---------|---------|
| 教程/干货 | 简约白、卡片式 |
| 观点/评论 | 杂志风 |
| 故事/案例 | 渐变色、杂志风 |
| 盘点/清单 | 卡片式、简约白 |
| 深度长文 | 杂志风、科技风 |
| 科技/编程 | 科技风 |

**半自动模式：** 列出模板选项让用户选择

## 使用方式

模板中有 2 个占位符：
- `{{TITLE}}` — 文章标题
- `{{CONTENT}}` — 正文 HTML

将文章内容转为内联样式 HTML 后，替换 `{{CONTENT}}` 即可。
