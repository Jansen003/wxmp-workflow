# 文章模板

5 个精美的公众号 HTML 模板，所有样式均为内联样式，兼容微信编辑器。

## 模板列表

| 模板 | 文件 | 风格 | 适合文章类型 |
|------|------|------|-------------|
| 简约白 | `minimal-white.html` | 大量留白、干净利落 | 干货、教程、工具推荐 |
| 杂志风 | `magazine.html` | 图文混排、优雅有层次 | 深度长文、观点评论 |
| 暗色系 | `dark-mode.html` | 深色背景、科技感 | 科技、编程、夜读 |
| 卡片式 | `card-style.html` | 模块化卡片、易扫描 | 清单、盘点、资源整理 |
| 渐变色 | `gradient.html` | 彩色渐变、年轻活力 | 生活方式、情感、故事 |

## 模板选择策略

**全自动模式：** AI 根据文章类型自动选择最匹配的模板

| 文章类型 | 推荐模板 |
|---------|---------|
| 教程/干货 | 简约白、卡片式 |
| 观点/评论 | 杂志风 |
| 故事/案例 | 渐变色、杂志风 |
| 盘点/清单 | 卡片式、简约白 |
| 深度长文 | 杂志风、暗色系 |
| 科技/编程 | 暗色系 |

**半自动模式：** 列出模板选项让用户选择

## 使用方式

模板中有 4 个占位符：
- `{{TITLE}}` — 文章标题
- `{{AUTHOR}}` — 作者名
- `{{DATE}}` — 发布日期
- `{{CONTENT}}` — 正文 HTML

将文章内容转为内联样式 HTML 后，替换 `{{CONTENT}}` 即可。
