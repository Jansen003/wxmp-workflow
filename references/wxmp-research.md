# 调研

大纲确定后、写稿之前，按大纲各章节搜集真实素材。凭空编造的内容缺乏说服力，好的素材能让文章更有深度和可信度。

## 何时跳过

- 用户已经提供了足够的素材（文档、链接、笔记）
- 用户说"不用调研，直接写"
- 选题本身不需要外部素材（如个人经验分享）

## 素材类型

| 类型 | 说明 | 怎么找 |
|------|------|--------|
| 竞品文章 | 同类公众号写过的类似选题 | WebSearch 搜索「{关键词} 公众号」 |
| 行业数据 | 支撑论点的数据和统计 | WebSearch 搜索「{行业} 报告 2026」 |
| 权威引用 | 专家观点、官方说法 | WebSearch 搜索「{人物} 说过 {观点}」 |
| 用户案例 | 真实的故事和经历 | 用户提供，或从公开渠道搜集 |
| 反面案例 | 失败案例、常见误区 | WebSearch 搜索「{主题} 踩坑」「{主题} 失败」 |

## 调研流程

1. **明确需要什么素材** — 根据大纲的每个章节，列出需要支撑的论点
2. **搜索竞品文章** — 看别人怎么写，找到可以借鉴的角度（不抄袭）
3. **搜集数据和引用** — 用 WebSearch 搜行业报告、专家观点
4. **整理素材包** — 按大纲结构组织，每个论点对应 1-2 个素材

## 输出格式

```
📦 素材包

### 选题：《xxx》

#### 一、引言部分
- 素材：xxx（来源：xxx）
- 素材：xxx（来源：xxx）

#### 二、核心论点1
- 数据：xxx（来源：xxx）
- 案例：xxx（来源：xxx）
- 引用：xxx（来源：xxx）

#### 三、核心论点2
- ...

💡 说明：以上素材供写稿时参考，不需要全部使用，挑选最有力的 2-3 个即可。
```

## 注意事项

- 素材要注明来源，方便用户核实
- 数据要尽量新（优先近 1 年的）
- 竞品文章只借鉴思路，不抄袭内容
- 如果搜不到合适的素材，如实告知，不要编造
