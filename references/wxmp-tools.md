# 增强工具集

随时可调用的工具，不绑定特定流程阶段。用户说"帮我想几个标题"或"帮我检查一下文章"时使用。

## 爆款标题生成器

基于文章内容生成多个标题选项，帮用户找到最有吸引力的那个。

### 何时使用

- 用户写完文章后不知道怎么取标题
- 用户对现有标题不满意
- 用户说"帮我想几个标题"或"标题太普通了"

### 怎么做

1. 通读文章全文，理解核心观点和目标读者
2. 用以下 5 种策略各生成 2 个标题，共 10 个：
   - **数字法**：用具体数字制造确定感（"5 个方法"、"3 分钟学会"）
   - **痛点法**：直击读者焦虑（"你还在 X？"、"为什么你总是 Y"）
   - **好奇法**：制造信息缺口（"这个方法让我月入 X"、"90% 的人不知道"）
   - **对比法**：制造反差（"从 X 到 Y，我只做了一件事"）
   - **权威法**：借助背书（"XX 亲测有效"、"行业大佬都在用"）
3. 每个标题附带一句话分析：为什么这样写、适合什么读者
4. 按推荐度排序，最推荐的放前面

### 输出格式

```
🏷️ 爆款标题候选（共 10 个）

⭐ 推荐
1. 《xxx》— 数字法，用具体数字降低阅读门槛
2. 《xxx》— 痛点法，直击目标读者的核心焦虑

📌 备选
3. 《xxx》— 好奇法，制造信息缺口吸引点击
4. 《xxx》— 对比法，用反差制造戏剧性
...

💡 分析：这篇文章的核心价值是 xxx，建议标题突出 xxx，避免 xxx。
```

## 摘要生成器

生成 120 字以内的公众号摘要，用于文章列表展示。

### 何时使用

- 用户不知道怎么写摘要
- 用户说"帮我写个摘要"或"摘要太长了"
- 在创建草稿前自动生成

### 怎么做

1. 通读文章，提炼核心观点
2. 摘要要满足：
   - 120 字以内（公众号限制）
   - 独立可读（不依赖标题）
   - 制造好奇心或承诺价值
   - 避免重复标题已表达的信息
3. 生成 3 个版本让用户选择：
   - **悬念型**：制造信息缺口，吸引点击
   - **价值型**：直接说明文章能给读者什么
   - **故事型**：用一个小故事/场景开头

### 输出格式

```
📝 摘要候选（共 3 个）

1. 悬念型：xxx
2. 价值型：xxx
3. 故事型：xxx

💡 建议：如果文章偏干货，选价值型；如果偏观点/故事，选悬念型或故事型。
```

## 文章体检报告

分析文章的可读性和传播力，给出具体优化建议。

### 何时使用

- 用户写完文章想优化
- 用户说"帮我看看这篇文章怎么样"
- 用户说"有没有什么可以改进的"
- 在转 HTML 之前做一次体检

### 怎么做

从以下 5 个维度打分（每项 1-5 分），并给出具体改进建议：

| 维度 | 检查什么 |
|------|---------|
| 开头吸引力 | 前 3 行是否能抓住读者？有没有制造好奇/痛点/悬念？ |
| 段落可读性 | 段落是否够短（≤4行）？是否有留白？是否适合手机阅读？ |
| 结构清晰度 | 小标题是否清晰？逻辑是否连贯？读者能否扫读？ |
| 金句密度 | 是否有值得划线/转发的句子？大约每 500 字一个金句？ |
| 结尾引导力 | 是否有互动引导（点赞/在看/评论/转发）？ |

### 输出格式

```
📊 文章体检报告

总体评分：xx/25

| 维度 | 评分 | 说明 |
|------|------|------|
| 开头吸引力 | x/5 | 具体分析... |
| 段落可读性 | x/5 | 具体分析... |
| 结构清晰度 | x/5 | 具体分析... |
| 金句密度 | x/5 | 具体分析... |
| 结尾引导力 | x/5 | 具体分析... |

🔧 优化建议：
1. 具体建议（对应哪个维度）
2. 具体建议
3. 具体建议
```

## 去 AI 味检查

检查文章中常见的 AI 写作痕迹，逐条指出并给出修改建议。

### 何时使用

- 文章写完后、体检报告之前
- 用户说"这文章一看就是 AI 写的"
- 用户说"帮我改得像人写的"
- 每篇文章必经步骤

### 怎么做

逐条扫描以下常见 AI 痕迹，找到就列出原文并给出修改建议：

| 类型 | 典型表现 | 怎么改 |
|------|---------|--------|
| 套话开头 | "在当今社会""随着...的发展""不可否认""众所周知" | 直接切入：用数据、故事、问题开头 |
| 刻板结构 | "首先...其次...最后""第一...第二...第三" | 换成自然过渡，或只保留重点，删掉凑数的 |
| 排比堆砌 | 连续 3 个以上结构相同的句子 | 只留最有力的一个，其他换表达方式 |
| 书面腔 | "赋能""助力""旨在""致力于""深入探讨" | 换成口语："帮你""让...更""就是想搞明白" |
| 两面讨好 | "一方面...另一方面""既有优点也有缺点" | 亮明立场，敢下判断 |
| 总结套话 | "总之""综上所述""总而言之" | 直接说结论，或用金句收尾 |
| 节奏单一 | 每段都差不多长，3-4 句 | 长短交替：有的段就一句话，有的展开讲 |
| 称呼疏远 | 大量用"我们" | 换成"你""我"，像跟朋友聊天 |
| 举例空泛 | "很多人""有些人""有研究表明" | 用具体的人、具体的数、具体的场景 |
| 过度客套 | "希望这篇文章对你有帮助""感谢阅读" | 删掉，或换成有态度的结尾 |

### 输出格式

```
🔍 去 AI 味检查

发现 x 处 AI 痕迹：

1. ❌ 套话开头
   原文："在当今社会，AI 技术正在改变..."
   ✅ 改成："上周我用 ChatGPT 写了个方案，老板竟然没看出来。"

2. ❌ 刻板结构
   原文："首先，我们需要...；其次，我们应该...；最后，我们还要..."
   ✅ 改成：删掉"首先/其次/最后"，直接讲重点

...

💡 总体评估：AI 味 xx/10（10=纯AI，1=完全不像AI）
```

## 话题标签推荐

根据文章内容推荐适合的公众号话题标签。

### 何时使用

- 用户说"帮我加几个标签"
- 在发布前自动推荐

### 怎么做

1. 提取文章的核心关键词（3-5 个）
2. 结合公众号热门话题，推荐标签
3. 每个标签说明为什么适合这篇文章

### 输出格式

```
🏷️ 话题标签推荐

推荐标签：
1. #关键词 — 理由
2. #关键词 — 理由
3. #关键词 — 理由

💡 标签不宜过多，3-5 个为佳。优先选搜索量大但竞争适中的标签。
```
